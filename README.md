# Osdmaverick Virtual Science Lab

**Explore. Experiment. Discover.**

An interactive, browser-based science learning platform for learners across multiple grade levels and curricula.

## Project structure

- `index.html` — project homepage and navigation.
- `human-body-systems.html` — Grade 7 Human Body Systems virtual lab.
- `assets/styles.css` — responsive site styling.
- `assets/main.js` — accessible mobile navigation.

## Run locally

Open `index.html` in a modern browser. The core pages use plain HTML, CSS and JavaScript and require no build step.

## Deploy with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment to complete. The site URL will appear in the Pages settings.

## Learning and safety note

Simulation values are illustrative educational models, not medical measurements or diagnostic guidance. Curriculum labels should be checked against the relevant local standards before classroom use. Do not enter sensitive student information into public pages.
